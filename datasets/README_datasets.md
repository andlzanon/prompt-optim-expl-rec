# datasets/

This directory centralizes both the source data and the generated artifacts
used throughout the recommendation, explanation-path extraction, LOD
explainability, and LLM-based explainability pipelines.

## Overview

```text
datasets/
├── explanation_paths/
├── explanation_raw_files/
├── knowledge-graphs/
├── lod_results/
├── ml-latest-small/
├── preprocessing/
├── preselected_explanation_paths/
├── recommendation_files/
├── recommender_train_test_oficial/
├── recommender_train_validation/
├── recs_to_expl_format/
├── user_split_train_val_test/
└── README_datasets.md
```

## What each folder contains

### `ml-latest-small/`

Base MovieLens Latest Small files used in the project.

Main files:

- `movies.csv`
- `ratings.csv`
- `links.csv`
- `tags.csv`
- `README.txt`

### `preprocessing/`

Helper scripts used to build dataset splits and derived files consumed by the
pipeline.

Current files:

- `train_test.py`
- `opt_train_validation.py`
- `kfold_creation.py`

In practice, this folder supports the creation of:

- `recommender_train_test_oficial/`
- `recommender_train_validation/`

### `recommender_train_test_oficial/`

Main train/test split used by the recommenders and by the explainability
stages.

Files:

- `train.csv`
- `test.csv`

### `recommender_train_validation/`

Train/validation split used in optimization procedures.

Files:

- `opt_train.csv`
- `opt_validation.csv`

### `recommendation_files/`

Outputs generated by the `recommender/` module.

Structure:

```text
recommendation_files/
├── recommendation_lists/
└── recommendation_metrics/
```

#### `recommendation_lists/`

Recommendation lists for:

- `bprmf`
- `item_knn`
- `ncf`
- `user_knn`

Each algorithm is organized by:

- `params_default` or `params_optimized`
- `K` value

Real examples:

- `recommendation_lists/ncf/params_default/K=20/default_ncf_K=20_recs.csv`
- `recommendation_lists/ncf/params_optimized/K=20/optimized_ncf_K=20_recs.csv`
- `recommendation_lists/item_knn/params_optimized/K=50/optimized_item_knn_K=50_recs.csv`

#### `recommendation_metrics/`

Metrics and saved parameter summaries for the same recommendation runs.

Real examples:

- `recommendation_metrics/ncf/params_default/K=20/default_ncf_K=20_metrics.csv`
- `recommendation_metrics/ncf/params_default/K=20/default_ncf_K=20_params.csv`
- `recommendation_metrics/user_knn/params_optimized/K=20/optimized_user_knn_K=20_metrics.csv`
- `recommendation_metrics/user_knn/params_optimized/K=20/optimized_user_knn_K=20_params.csv`

### `knowledge-graphs/`

Knowledge-graph files used to build candidate explanation paths.

Files:

- `props_wikidata_movielens_small.csv`
- `props_artists_id.csv`

The main file consumed by the current pipelines is:

- `props_wikidata_movielens_small.csv`

### `explanation_paths/`

Per-user candidate explanation paths generated from the optimized
recommendation lists with `K=20`.

Current subfolders:

- `bprmf-opt/`
- `item_knn-opt/`
- `ncf-opt/`
- `user_knn-opt/`

Each file corresponds to one user from one specific algorithm.

Real examples:

- `explanation_paths/ncf-opt/ncf_2_user_id.csv`
- `explanation_paths/item_knn-opt/item_knn_550_user_id.csv`
- `explanation_paths/bprmf-opt/bprmf_100_user_id.csv`

These files are consumed by the current LLM pipeline and by
`run_prepare_selected_paths.py`. The current `explainability-LOD/` baseline
does not read `datasets/explanation_paths/`.

### `preselected_explanation_paths/`

Precomputed files for the LLM stage. Instead of reading all raw candidate
paths user by user, the LLM pipeline consumes a prepared `selected_paths.csv`
for each algorithm and user scope.

Current algorithm subfolders:

- `bprmf/`
- `item_knn/`
- `ncf/`
- `user_knn/`

Each algorithm has two scopes:

- `optimization`: train + validation users
- `explainability`: test users

Real examples:

- `preselected_explanation_paths/ncf/optimization/random/recs_10_paths_10/seed_2026/selected_paths.csv`
- `preselected_explanation_paths/ncf/optimization/random/recs_10_paths_10/seed_2026/selected_paths_metadata.json`
- `preselected_explanation_paths/ncf/explainability/random/recs_10_paths_10/seed_2026/selected_paths.csv`
- `preselected_explanation_paths/item_knn/explainability/random/recs_10_paths_10/seed_2026/selected_paths_metadata.json`

### `recs_to_expl_format/`

Legacy or auxiliary artifacts that convert recommendation outputs into a
named/textual format. The current main entry points do not reference this
folder directly.

Main files and subfolders:

- `main.py`
- `train_llm.csv`
- `recommendation_lists/`

#### `train_llm.csv`

Generated interaction-history artifact with movie titles, produced by
`main.py`. It is present in the repository but is not read by the current
`explainability-with-LLMs/` or `explainability-LOD/` entry points.

#### `recommendation_lists/`

Named versions of the recommendation lists, organized by algorithm,
configuration, and `K`.

Real examples:

- `recs_to_expl_format/recommendation_lists/ncf/params_optimized/k=20/named_optimized_ncf_K=20_recs.csv`
- `recs_to_expl_format/recommendation_lists/user_knn/params_default/k=100/named_default_user_knn_K=100_recs.csv`

Note:

- this folder contains both `K=` and `k=` directory names; this reflects how
  these artifacts were originally generated and preserved in the repository

### `user_split_train_val_test/`

User partition files used by the current LLM pipeline.

Files:

- `train_users.csv`
- `val_users.csv`
- `test_users.csv`
- `split_meta.json`

These are the split files used by the current LLM pipeline by default.

### `explanation_raw_files/`

Legacy folder containing a copy of the user split files:

- `explanation_raw_files/user_split_train_val_test/train_users.csv`
- `explanation_raw_files/user_split_train_val_test/val_users.csv`
- `explanation_raw_files/user_split_train_val_test/test_users.csv`
- `explanation_raw_files/user_split_train_val_test/split_meta.json`

Important:

- the LLM pipeline uses `user_split_train_val_test/`
- the `explainability-LOD/` baseline still references
  `explanation_raw_files/user_split_train_val_test/`

### `lod_results/`

Outputs generated by the non-LLM baseline (`explainability-LOD/`).

Structure:

```text
lod_results/
├── average_metrics/
├── individual_metrics/
└── output/
```

Real examples:

- `lod_results/output/output_explanations_optimized_ncf_K=20_recs.csv`
- `lod_results/individual_metrics/indiv_metrics_explanations_optimized_ncf_K=20_recs.csv`
- `lod_results/average_metrics/avg_metrics_explanations_optimized_ncf_K=20_recs.csv`

Extra artifact present in the repository:

- `lod_results/lod_metrics.xlsx`

The current `python explainability-LOD/run_LOD.py` pipeline writes the three
directories above, but it does not generate `lod_metrics.xlsx`.

## Generation flow for the main artifacts

### 1. Recommendation

Command:

```bash
python recommender/main_recommendation.py
```

Main outputs:

- `recommendation_files/recommendation_lists/`
- `recommendation_files/recommendation_metrics/`

### 2. Raw explanation paths

Command:

```bash
python knowledge-graphs/find_explanation_paths.py
```

Outputs:

- `explanation_paths/<algorithm>-opt/<algorithm>_<userId>_user_id.csv`

### 3. LOD baseline

Command:

```bash
python explainability-LOD/run_LOD.py
```

Outputs:

- `lod_results/output/`
- `lod_results/individual_metrics/`
- `lod_results/average_metrics/`

### 4. Preparation for LLMs

Command:

```bash
bash explainability-with-LLMs/bash/run_prepare_selected_paths.sh
```

Outputs:

- `preselected_explanation_paths/<algorithm>/<user_scope>/.../selected_paths.csv`
- `preselected_explanation_paths/<algorithm>/<user_scope>/.../selected_paths_metadata.json`

## Quick summary

If the main question is "which folders are source inputs and which ones are
generated outputs?", the practical split is:

Raw source inputs:

- `ml-latest-small/`
- `knowledge-graphs/`

Stored splits used as pipeline inputs:

- `recommender_train_test_oficial/`
- `recommender_train_validation/`

Generated artifacts used by the current pipelines:

- `recommendation_files/`
- `explanation_paths/`
- `preselected_explanation_paths/`
- `lod_results/`

Generated support data used by the current LLM pipeline:

- `user_split_train_val_test/`

Support or compatibility folders:

- `preprocessing/`
- `recs_to_expl_format/`
- `explanation_raw_files/`
