# 📋 Reproduction

## Environment 

To run the recommendation generation, navigate to "recommender/", then run: 
    
    python main_recommendation.py [algorithm] [k_values separated by spaces]

    [algorithms]: userknn, itemknn, ncf, bprmf, all
    [k_values separated by spaces]: any value under 200
